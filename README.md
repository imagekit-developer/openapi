# ImageKit's OpenAPI Specification

This repository contains an [OpenAPI](https://spec.openapis.org/oas/v3.1.0.html) specification for the [Image Kit API](https://imagekit.io/docs/api-reference).

## Spec

> [!CAUTION]
> This spec is primarily intended for Image Kit's internal use. Stability of the spec is not guaranteed.

[**View the spec**](openapi.yml)

## Clients

Our official clients are generated from this spec:

- [imagekit-nodejs](https://github.com/imagekit-developer/imagekit-nodejs) (TypeScript)
- [imagekit-python](https://github.com/imagekit-developer/imagekit-python) (Python)
- [imagekit-go](https://github.com/imagekit-developer/imagekit-go) (Go)
- [imagekit-java](https://github.com/imagekit-developer/imagekit-java) (Java)
- [imagekit-ruby](https://github.com/imagekit-developer/imagekit-ruby) (Ruby)
